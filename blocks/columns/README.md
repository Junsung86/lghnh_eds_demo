# columns

Custom **columns** block. Purpose: columns family: promo cards, pull-quote, about split, product summary and purchase info.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, 2-3 cells (columns-product: image | category link, h1 name, rating, price with discount/strong sale/del original, shipping; columns-info: 3 x h3 + body text/list).

## Supported variations

| Variation | Option class |
| --- | --- |
| Promo | `columns-promo` |
| Pullquote | `columns-pullquote` |
| About | `columns-about` |
| Product | `columns-product` |
| Info | `columns-info` |
