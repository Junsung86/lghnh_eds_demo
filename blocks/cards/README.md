# cards

Custom **cards** block. Purpose: cards family: article teasers, dark feature cards, related product tiles and product-line promo cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: image | body (cards-product: name link + price; cards-brandline: tagline + bold name + text link).

## Supported variations

| Variation | Option class |
| --- | --- |
| Article | `cards-article` |
| Feature | `cards-feature` |
| Product | `cards-product` |
| Brandline | `cards-brandline` |
